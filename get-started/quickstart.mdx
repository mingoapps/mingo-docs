## Authentication

All API requests require authentication. Mingo supports two authentication methods:

### 1. Magic Link DID Authentication

```bash
# Example request to authenticate with Magic Link DID
curl -X POST https://api-dev.mingo.com/auth/login/did \
  -H "Content-Type: application/json" \
  -d '{
    "did_token": "your_magic_link_did_token"
  }'
```

### 2. Hedera Key Pair Authentication

```bash
# Example request to authenticate with Hedera key pair
curl -X POST https://api-dev.mingo.com/auth/login/key \
  -H "Content-Type: application/json" \
  -d '{
    "public_key": "your_public_key",
    "signature": "your_signature"
  }'
```

After successful authentication, you'll receive a Bearer token that must be included in all subsequent requests:

```bash
# Example of making an authenticated request
curl https://api-dev.mingo.com/event \
  -H "Authorization: Bearer your_auth_token"
```

## Making Your First Request

1. Choose your authentication method (Magic Link DID or Hedera key pair)
2. Authenticate to get your Bearer token
3. Include the token in the Authorization header of your requests
4. Start making API calls to Mingo's endpoints

## Best Practices

- Always use HTTPS for API requests
- Store your authentication tokens securely
- Implement proper error handling
- Use the development environment for testing
- Follow rate limiting guidelines
