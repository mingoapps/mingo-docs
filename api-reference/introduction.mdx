## Overview

Mingo's REST API provides a comprehensive interface for integrating with our Web3 ticketing platform. Our API enables you to build applications that interact with digital assets, event ticketing, and NFT collections powered by Hedera Hashgraph.

## Core Concepts

### Authentication

Mingo's API supports two authentication methods:

- **Magic.link DID Authentication**: For web3 wallet-based authentication
- **Hedera Key Pair Authentication**: For direct Hedera account access

All authenticated requests require a Bearer token in the Authorization header.

### Events and Ticketing

The API provides comprehensive event management capabilities:

- Create and list events
- Manage ticket types and pricing
- Handle ticket purchases and redemptions
- Track event attendance

### NFT Collections

Manage NFT collections with features for:

- Launching new collections
- Managing collection metadata
- Handling NFT purchases
- Tracking collection ownership

### Wallet Management

Interact with Hedera wallets to:

- View wallet assets
- Check token balances
- Monitor transaction history
- Manage digital assets

## Getting Started

To begin using Mingo's API:

1. Choose your authentication method (Magic.link or Hedera key pair)
2. Obtain your API credentials
3. Make your first authenticated request
4. Explore the available endpoints for your use case

- Always use HTTPS for API requests
- Implement proper error handling
- Cache responses when appropriate
- Follow rate limiting guidelines
- Keep your authentication tokens secure
