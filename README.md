# Mingo Developer Documentation

Welcome to Mingo's official developer documentation. This documentation provides comprehensive guides and API references for integrating with Mingo's Web3 platform.

## What is Mingo?

Mingo is bringing crypto to the masses through a unified ecosystem for digital assets, ticketing, gaming, and NFTs—powered by Hedera Hashgraph. Our platform provides a comprehensive suite of tools and APIs for developers to integrate and build upon our infrastructure.

## Documentation Features

- REST API Reference
- Authentication Guides
- Event Management
- NFT Collection Management
- Wallet Integration
- Best Practices
- Code Examples

## Development

To contribute to this documentation:

1. Install the [Mintlify CLI](https://www.npmjs.com/package/mintlify):

```bash
npm i -g mintlify
```

2. Run the development server:

```bash
mintlify dev
```

## Publishing Changes

Changes to the documentation are automatically deployed when pushed to the main branch. The documentation is built and deployed using Mintlify's platform.

## Support

For technical support or questions about the API, contact our engineering team at <engineering@mingo.com>.

## Troubleshooting

- If Mintlify dev isn't running, try `mintlify install` to re-install dependencies
- If pages load as 404, ensure you're running in a folder with `docs.json`
